# Centralized School Management System

Mini Project by Ragul and Team

A Java-based Centralized School Management System built using JavaFX, Oracle Database, and JDBC.

## Features
- User Authentication (Login / OTP)
- Student Dashboard
- Attendance Management
- Assignments & Submissions
- Marks & Performance Tracking

## Tech Stack
- Java (Core + JavaFX)
- Oracle Database (SQL*Plus)
- JDBC
- FXML + CSS

## Setup Instructions

### 1. Clone the repository
git clone https://github.com/VishwaaT27/Centralized-School-Management-System.git

### 2. Setup Database
Run:
@database/setup.sql

### 3. Configure Environment Variables
Set these before running the app:

CSMS_DB_URL=jdbc:oracle:thin:@localhost:1521/XEPDB1
CSMS_DB_USER=CSMS
CSMS_DB_PASSWORD=your_database_password
CSMS_EMAIL=your_email@gmail.com
CSMS_EMAIL_PASSWORD=your_gmail_app_password

### 4. Compile & Run
Use your existing commands from terminal
