# Centralized School Management System

Mini Project by Ragul and Team

A Java-based Centralized School Management System built using JavaFX, Oracle Database, and JDBC.

## Features
- User Authentication (Login / OTP)
- Student Dashboard
- Attendance Management
- Assignments & Submissions
- Marks & Performance Tracking

## Tech Stack
- Java (Core + JavaFX)
- Oracle Database (SQL*Plus)
- JDBC
- FXML + CSS

## Setup Instructions

### 1. Clone the repository
git clone https://github.com/VishwaaT27/Centralized-School-Management-System.git

### 2. Setup Database
Run:
@database/setup.sql

### 3. Configure Local Database Settings
Copy `config.example.bat` to `config.local.bat`, then update your local Oracle username, password, and URL.

`config.local.bat` is ignored by Git so local credentials are not pushed.

### 4. Compile & Run
Run:
run.bat
